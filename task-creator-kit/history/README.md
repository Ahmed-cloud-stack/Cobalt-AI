# Historical scripts

These are the retained scratch scripts from the shutter revision workflow. They document how the candidate was edited, submitted and graded. The panel, knot and curve edits are one-off transformations of specific intermediate trees under /tmp. They have historical paths and assume those exact intermediate files and prior edits. The runner, seal, fixture cache and Harbor launcher likewise assume the original scratch layout. Use the portable replacements in ../scripts for a new task.

The complete resulting source and active fixture generators are in ../examples. A creator wrote the task-specific instructions, starter, reference and independent numerical verifier through iterative edits. There was no universal task generator. The examples preserve the reproducible final code rather than trying to replay the entire interactive design history. Private attempt code, cached answers, credentials and machine-specific settings are omitted.
